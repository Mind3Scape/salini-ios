# Выделение Salini iOS в отдельный репозиторий

Дата: **13 октября 2026**.

Исходный репозиторий: [`Mind3Scape/solini-render-studio`](https://github.com/Mind3Scape/solini-render-studio).

Ветка: `codex/salini-room-ar`; точный источник переноса: [`ee56a2267adba72999ce03bac8351c21bd89184d`](https://github.com/Mind3Scape/solini-render-studio/tree/ee56a2267adba72999ce03bac8351c21bd89184d).

Источник архива TestFlight 1.0 (12): [`def568a65e8246093a6093ff9f07c2fdcd312bf7`](https://github.com/Mind3Scape/solini-render-studio/commit/def568a65e8246093a6093ff9f07c2fdcd312bf7). Код, тесты, проект и ресурсы приложения при переносе не изменяются; различия между этими коммитами в релизной документации и отдельных исследованиях не являются новой версией приложения.

## Что перенесено

- Всё отслеживаемое дерево `ios/`: исходники, готовый проект, тесты, данные и медиа, происхождение ресурсов, инструменты, исторические проверки и релизные подтверждения.
- Три инвентаризации сайта, на которые опираются инструменты подготовки данных.
- Оригинальный текст лицензии кода с сохранением copyright.
- Новая навигация по проекту и документация для команды Salini.

Для всех 729 исходных файлов `ios/` сохранены SHA-256 в [`import-manifest.json`](import-manifest.json). Последующие изменения документов и результаты проверки перечислены в [`migration-validation.json`](migration-validation.json).

## Что осталось в исходном репозитории

Render Studio, веб-интерфейсы, сайт, архив исследований, большие исходные загрузки и отдельный эксперимент с графикой Insight. Исходный репозиторий не очищался и его история не переписывалась.

Новый репозиторий начинается с самостоятельного снимка приложения. Смешанная история веб-студии и исследований не переносилась. Для поиска причин прежних изменений используйте [историю iOS по исходному коммиту](https://github.com/Mind3Scape/solini-render-studio/commits/ee56a2267adba72999ce03bac8351c21bd89184d/ios/). Старые ссылки на исследования в Markdown направлены в исходный репозиторий с закреплённым коммитом.

## Дальнейшая работа

Новые изменения основного приложения ведутся здесь, в ветках `codex/<задача>`, с проверкой и включением в `main`. Перенос изменений из оставшихся экспериментальных веток выполняется явно после приёмки; двусторонней автоматической синхронизации репозиториев нет.

Существующий TestFlight и приложение в App Store Connect остаются теми же. GitHub-репозиторий публичный, как и источник; просмотр кода доступен без приглашения, права записи менеджеру не выдавались.
