# Единый опыт сайта и приложения · 22.10.2026

Ветка `codex/unified-salini-experience`, основа — опубликованный main/build 12. Приложение остаётся нативным UIKit; сайт живёт отдельно в `Mind3Scape/salini-website`.

## Изменения

- Официальная фотография Paola 172 и согласованный с сайтом первый экран; входы в четыре основные категории.
- Избранные формы главной используют канонический каталог и фотографии вместо старой модели четырёх демо-товаров.
- Семантические токены SaliniBrand, continuous corners, системный serif для редакционных заголовков, скруглённые фотографии.
- `salini://product/{id}?v=1` открывает карточку по каноническому ID.
- `salini://selection?v=1&ids=...` объединяет до 100 известных ID с избранным. Не создаёт строки проекта, не выбирает исполнение, не изменяет количество/цвет. Неизвестные ID отклоняются целиком, дубли удаляются.
- Из карточки и избранного доступен системный share sheet с веб-ссылкой.

Сайт использует точные байты `ios/Salini/CatalogMedia/catalog.json`: 305 изделий, 539 исполнений. SHA-256 `7f74c9db73467daaea02c6c5c4063fcb44e91066fc724021463b622dc19b49be`. Общие токены и контракт ссылок копируются из версионированных `shared/` сайта его генератором. Нельзя независимо менять публичные ID или формат ссылки без изменения версии контракта.
