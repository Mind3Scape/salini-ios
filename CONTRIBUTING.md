# Работа с проектом

`main` — общая проверенная основа приложения. Для каждой задачи создавайте ветку `codex/<краткое-название>`, описывайте ожидаемое поведение и открывайте pull request после соответствующей проверки.

В описании изменений укажите, что изменилось, как проверено и какие ограничения остаются. Для интерфейса нужны реальные кадры работающего приложения. Рендер или проверка в браузере не заменяют проверку iOS.

Не добавляйте в Git пароли, API-ключи, сертификаты, профили подписи, сборки, локальные журналы и личные данные клиентов. Изменения происхождения или лицензий ресурсов фиксируйте вместе с самими ресурсами.

Проверка и публикация описаны в [BUILDING.md](docs/BUILDING.md) и [RELEASES.md](docs/RELEASES.md). Доступ на чтение к этому публичному репозиторию не даёт права записи и доступа к App Store Connect.
