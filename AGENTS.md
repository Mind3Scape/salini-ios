# Salini iOS working agreements

- Scope: only the Salini iOS application. Do not edit or message Balance / BalanceOS or other projects.
- This repository is the independent app home. Keep Render Studio, web publishing and unaccepted graphics experiments outside the release app unless explicitly approved.
- Preserve unrelated work. Commit and push task-related changes before reporting implementation complete. Use `codex/` branches for new work.
- Existing collaboration preference: Opus through Claude Code implements app features; Codex directs, reviews, builds and checks the running app. Repository packaging and documentation do not require changing app behavior.
- Do not claim browser or offline render checks as native iOS verification. Simulator AR does not verify physical camera tracking.
- Consult `docs/RELEASES.md` before distribution. Build 12 was already released; never re-upload it because the repository moved. Verify later build numbers against App Store Connect.
- Preserve source attribution and licences. Keep credentials, build outputs, raw source downloads and local QA scratch files out of Git.
