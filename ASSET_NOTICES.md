# Источники и права на ресурсы

Этот репозиторий выделен из существующего проекта. Текст MIT-лицензии исходного кода сохранён в `LICENSE`; он не предоставляет права на все включённые изображения, товарные знаки и сторонние материалы.

- **Salini:** логотип, фотографии, описания и официальные USDZ-модели получены с сайта и из презентационных материалов бренда. Права сохраняются за правообладателями. Источники: [`ios/ASSET_SOURCES.json`](ios/ASSET_SOURCES.json) и поля происхождения в [`catalog.json`](ios/Salini/CatalogMedia/catalog.json).
- **Insight:** точные источники, авторы, лицензии и контрольные суммы сторонних моделей, HDRI и текстур записаны в [`ios/Salini/InsightAssets/ASSETS.json`](ios/Salini/InsightAssets/ASSETS.json). У записей Salini права сохранены за брендом; статус CC0 сторонних ресурсов на них не распространяется.
- **Навигационные иконки Soft, Gregor Cresnar / Noun Project:** исходный манифест указывает загрузку по Noun Project Pro — Royalty-Free License и содержит авторство и ссылки для каждой иконки. Сохранён в [`PROVENANCE.json`](ios/design/icons/soft/PROVENANCE.json). Это не часть MIT-лицензии кода; отдельное распространение набора иконок не разрешается автоматически наличием файлов в репозитории.
- **Авторские генерированные сцены и фильмы:** визуальные концепции для приложения, созданные с использованием ИИ. Они не являются фотографиями фактического производства, точной цветопробой или доказательством характеристик изделий. Исторические источники и процессы доступны через [архив исследований](https://github.com/Mind3Scape/solini-render-studio/tree/ee56a2267adba72999ce03bac8351c21bd89184d/research).

Сведения о происхождении перенесены вместе с ресурсами. Сам факт публичного доступа к GitHub не меняет условия использования сторонних материалов.
